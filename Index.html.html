What this tab finds

Big institutions accumulate quietly over days — their algos drip-feed orders so it almost never appears as a reported bulk/block deal (which is what the Smart Money tab catches). What it does leave behind is a rising volume footprint: each session trades more than the 20-day norm, and the ratio keeps climbing. This tab surfaces exactly those names so you spot accumulation before the breakout.

The date window

Mirrors the Smart Flow filter — it sets how many sessions "buildup" is measured over:
Today rank purely by today's volume vs its 20-day average (single-day shockers).
This Week 5-session buildup — the classic staircase. Default.
This Month ~20-session buildup — slower, structural accumulation.
Custom pick any start/end date to measure buildup over that exact span.

Reading the columns

Last 5 price action — green ↑ = closed up, red ↓ = down, oldest→newest. Sits next to the symbol everywhere.
Volume bars each bar = that session's volume ÷ 20-day average. Newest bar highlighted. A rising staircase = building up.
RVOL × latest session's volume vs 20-day average. 2.0× = twice the normal volume today.
Trend ▲ Rising / ■ Flat / ▼ Fading — slope of the volume bars across the window.
EMA your category — 🟢 A, 🟡 B, 🔵 C, 💎 A+C (hover each for the rule).
Setup active breakout / Qullamaggie pattern (EP, VCP, HTF, Reclaim) if any.
Results latest earnings grade from the Results tab.
Smart $ smart-money tier from bulk/block deals — accumulating or distributing.
Score RVOL×16 + slope×14 + (sustained>1.4× ? +12), capped 0–100. Sorts the leaderboard.

How to use it

The best longs line up: rising volume + Cat A/A+C + a breakout setup + accumulating smart money. Use "Rising only" + RVOL ≥ 2× to cut noise, then scan the cross-reference chips for confluence. Falling volume on a Cat-A name can flag a stalling move early.
